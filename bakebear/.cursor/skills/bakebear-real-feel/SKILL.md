# 巴克熊：贴近真实（现行法）

创始人目的（高于仓库里任何旧锁）：

平行世界里这只，在动作、表情、互动上要非常贴近真实世界。主人看它、摸它、给它，都要感到几乎接近真实的反馈。包括视觉逼真和流畅，也包括它给主人的反馈：当下立刻回，和隔夜还记得。

过关线改成一句：**摸头、摸尾巴、连摸、喂、洗，像不像家里那只。**
「第三人认得出是这只」仍要。认不出脸，再顺也是别的动物。

## 两层反馈（必须都做，不要混）

### 当下（手还没离开）

摸、喂、洗、溜、追手指：身体先动，字后到。慢拖是溜（手指领路）；点地或甩快是追（手指是猎物）。猫溜可以停、可以不走。

- 从触摸到第一下可见身体变化：猫 ≤ 300ms，狗 ≤ 150ms，胆小再加一点。睡着先醒，醒得慢
- 超过 500ms 还没动 = 失败。主人会觉得点的是按钮
- 部位必须不同：头靠过来；背塌 / 邀玩；腰痒；尾巴猫躲狗摇
- 连摸会腻：同一处 3 下，或 90 秒内 4 下，走开或舔毛
- 喂：先闻再舔。喂到尾巴，猫说那不是嘴，连喂会拒
- 洗：猫躲、狗抖。没淋到要看得出
- 不要用一颗心代替身体

### 隔夜（人已经走了）

延迟反馈是记得，不是任务。

- 摸过的部位留下，隔夜或进门会再提
- 打雷还想着；下雨但没有轰隆隆，不躲
- 特性满 3 且隔夜宣布后，日子权重要变（胆小多睡坐、被摸更犹豫）
- 不要做成每日任务条、饥饿、经验

## 猫 / 狗必须两套（不是换皮加速）

同一句「在吗 / 晚安 / 想你了 / 摸 / 给」，猫和狗的动词、延迟、拒法都不同。

猫（约 ≤300ms）：先僵再靠；舔爪、哈欠、眩眼更疏；尾巴躲开；洗是躲；训是看我 / 过来 / 扑；可以不跟溜。
狗（约 ≤150ms）：摸头歪头；甩毛、追、眩眼更勤；尾巴摇；洗是抖；训是看我 / 过来 / 趴下；溜跟一侧。

现有帧演不像「家里那只」时，为这一只补，用它自己的锁图。出帧仍按 `docs/动作-过关.md`：同一张锁图只改这一下，切帧不挪图。透过底、短动甩尾是出图手艺，不是上架卖贴纸。

## 视觉：顺，并且是这只

- 走 50ms 一小步，整像素。先转向再挪。追近减速，不要每拍硬跳
- 切帧预载下一张再亮，叠化可以加到流畅，不要闪
- 跳的高低、迈腿写在帧里。空地不要用 translate/rotate/压扁假装迈腿
- 开口、眩眼、空地过日子，脸必须是出卡那张锁图
