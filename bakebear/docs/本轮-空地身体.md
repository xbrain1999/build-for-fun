## 过关（真机）

1. 认得出是出卡那只。002 / 003 花纹不准套上来。
2. 同一句「摸它 / 在吗 / 晚安」：猫和狗动词不同，不是同一套加速。
3. 手还没离开：猫 ≤300ms，狗 ≤150ms。超过 500ms 算失败。
4. 头 / 背 / 腰 / 尾 各一下，部位看得出不一样。连摸三下该腻。
5. 喂先闻再舔；洗：猫躲狗抖。
6. 先留下：能存静帧或短动，不弹协议。不要新商店。
7. 不出现饥饿、经验、第二只、家具、一键发圈。

本地绿：`node tools/check_feel.js`。绿盖不住真机手感，真机为大。
